Images PowerPoint & PDF

Récupérez les images d'un PowerPoint ou d'un PDF

Déposez un fichier pour voir toutes ses images, puis téléchargez celles que vous voulez dans leur qualité d'origine.

0 %

    Tout se passe dans votre navigateur : le fichier n'est envoyé sur aucun serveur.

    Bon à savoir
    • PowerPoint : vous obtenez le fichier image exact rangé dans la présentation, sans recompression.
    • PDF : les photos (JPEG) sont récupérées telles quelles ; les autres images sont reconstituées en PNG, à leur définition d'origine.
    • Si une image a été recadrée dans PowerPoint, c'est l'image complète, non recadrée, qui est récupérée.
    • Si la présentation a été enregistrée avec l'option « Compresser les images », PowerPoint a déjà réduit leur définition : la qualité perdue ne peut pas être retrouvée.
    • Les formats EMF et WMF (dessins vectoriels de Windows) ne s'affichent pas dans le navigateur mais peuvent être téléchargés.
    • Les anciens fichiers .ppt ne sont pas pris en charge : ouvrez-les dans PowerPoint et enregistrez-les en .pptx.
    • Les PDF chiffrés (protégés contre la copie) et les images de scans noir et blanc (JBIG2, CCITT) ne sont pas pris en charge.
